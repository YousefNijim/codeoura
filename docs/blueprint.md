# **App Name**: Codeoura Landing

## Core Features:

- Hero Section Animation: Fade-in effect for the logo and slogan using Framer Motion.
- Interactive Service Cards: Interactive cards for Web Development, Accounting Software, and Mobile Apps.
- Engineering-First Explanation: Layout to highlight Codeoura's engineering-first approach and AI integrations.
- AI Integration Tool: An AI tool will decide, based on business goals and available features, what tech stack or platform is most appropriate for each user's individual situation, incorporating business rules and user preferences into its output.
- Portfolio Grid: A grid to show the previous accounting system projects with hover effects.
- Contact Form: A professional form to gather user info.
- Social Media Links: Provide links to all social media.

## Style Guidelines:

- Background color: Dark theme with #0f0f0f to maintain a sleek look.
- Primary color: Deep Blue (#3B5998), based on the prompt's request to incorporate the Codeoura brand colors.
- Accent color: Orange (#FF8C00), based on the prompt's request to incorporate the Codeoura brand colors. Provides a sharp contrast to the dark background and complements the Deep Blue.
- Headline font: 'Poppins' (sans-serif) for headlines, for a precise, contemporary look.
- Body font: 'PT Sans' (sans-serif) for the body, balancing modernity with a touch of warmth.
- Centered hero section with prominent logo and slogan.
- Responsive design to ensure a seamless experience on mobile devices.
- Use subtle fade-in effects for the hero section and hover effects for portfolio items to add a modern touch.
